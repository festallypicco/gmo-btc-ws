# docs — 文書の正本

このリポジトリの設計・運用に関する文書は、ここを正本とする（2026-11-06 確定の運用モデルに基づく）。

## 構成

- `spec/` — 仕様書・運用マニュアル（生きている正本。版数は v90 → v91… と上げる）
- `design/` — 変更ごとの詳細設計書（実装前に書き、日付＋テーマで命名）
- `review/` — レビュー記録・引き継ぎ照合メモ
- `operations/` — VPS構築手順書、運用モデル、チェックリスト等の運用資料

## 保守ルール

- コード変更の PR には、対応する文書の更新を同じ PR に含める
- 仕様が変わる変更では、仕様書の版をその PR で上げる
- 実装が設計書からずれた場合は、設計書側も直してからマージする
- 秘密情報（APIキー、パスワード等）は文書に書かない
